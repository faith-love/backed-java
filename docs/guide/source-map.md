# 参考站点知识地图：从主题索引到学习路径

参考站《JAVA 学习笔记》的分类覆盖 Java SE、并发、JVM、I/O、Spring、数据库、服务器、前端工具、分布式、操作系统、网络和设计模式。本知识库沿用这些主题，并按依赖关系排序，方便把“知道名词”推进到“读懂项目”。

## 按“解决的问题”理解技术

- **Java 类型和类**解决代码规模变大后如何约束对象结构、方法输入和输出的问题。
- **Spring IoC**解决对象之间互相创建、难以替换和难以测试的问题。
- **Spring MVC**解决 HTTP URL、方法、参数与 Java 业务代码如何对应的问题。
- **MyBatis**解决 SQL 与 Java 参数/结果映射重复且容易错位的问题。
- **事务**解决多个数据库操作只完成一部分、造成数据不一致的问题。
- **Gateway 和服务发现**解决浏览器不应记住每个服务地址、服务实例还会变化的问题。
- **消息队列**解决发送方和处理方必须同时在线、瞬时流量直接压垮处理端的问题。
- **观测与日志**解决请求跨多个系统后难以判断卡在哪一步的问题。

## 推荐学习路线

1. 学习 Java 对象、接口、集合、异常和泛型。
2. 学会用 Network 面板看 HTTP 方法、URL、Header 和 Body。
3. 学 Spring MVC 的参数绑定，再学 Controller/Service 分层。
4. 学 JDBC/MyBatis，理解 SQL、分页、事务和索引。
5. 了解线程池、缓存和微服务调用失败。
6. 回到 [数据中台项目地图](./project-map)，完整追一条仪表盘请求。

## 使用边界

参考站是个人笔记，适合作为知识主题索引。不同 Java/Spring 版本的默认行为会改变；本知识库给出的代码用于解释概念，具体结论还要核对项目版本和官方文档。
