# Examples｜实践示例

示例按“先看完整请求，再自己练”的方式组织。代码路径和真实响应字段以当前 checkout 为准。

## 示例

- [从前端请求追到后端](./request-walkthrough.md)：仪表盘列表和图表数据两条完整调用链。
- [练习路线](./learning-path.md)：从路径分析、响应解包到小型兼容性改动。
- [支付宝与微信支付实战](./online-payment.md)：下单与支付回调流程、官方 SDK 接入片段，以及可运行的并发重复通知模拟。
- [大文件与分片上传](./large-file-upload.md)：前端切片、并发与暂停，后端流式接收、校验、幂等合并、断点恢复及对象存储直传。

## 练习建议

先做静态阅读和 Network 对照，再尝试设置断点。动手改动时使用自己的分支和开发环境；涉及 SQL 或共享服务之前，先确认目标环境。
