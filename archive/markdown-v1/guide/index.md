# Guide｜阅读指南

本部分回答三个问题：当前项目由哪些服务组成、Java 后端代码如何分层、遇到接口问题从哪里开始排查。

## 章节

1. [学习地图](./project-map.md)：技术栈、服务模块和前端仓库。
2. [后端核心概念](./backend-concepts.md)：从前端熟悉的 API contract 理解 Java 分层。
3. [本地联调与排错](./debugging.md)：从浏览器 Network 追到网关、Controller 和数据层。

建议先看学习地图。之后选择一个接口配合 [仪表盘 API 参考](../api/dashboard-endpoints.md) 和 [端到端示例](../examples/request-walkthrough.md) 阅读。
